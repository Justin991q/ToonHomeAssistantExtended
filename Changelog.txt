1.2.0
- Binary sensors (motion, a door contact) light up while on; the toggle icon shows off (knob left) and on (right)
- Energie: yesterday up to this time (and yesterday's hours behind today's), today's costs with price entities
  (worked out per hour), and a Stroomprijs panel with today's price per hour (dynamic contracts) and the cheapest hour
- Energie: the history is fetched in full once, then only the readings since the last time (lighter for the Toon)
- Cameras: a moving picture (an animated GIF, e.g. a rain radar) plays and loops, and isn't fetched again every
  few seconds (only with a new camera token)
- Live updates over Home Assistant's WebSocket API (subscribe_entities): changes show at once; polling only when
  the connection is down (then every pollSeconds) or every 5 minutes for names and areas
- New tile: the first four favourites as mini cards in the main screen's style
- Live updates only redraw when something the app shows changed (not a speaker's position every second), so a tap
  isn't lost; an older poll's answer no longer replaces newer states; the speaker's source buttons stay put
- The original Home Assistant logo (tile, tile chooser, systray, screens, web editor)
- Fans: a tap on the card (or the tile) opens the fan screen instead of switching the fan
- Faster with many entities (hundreds): the list of all entities is cached on the Toon (fetched again after
  6 hours, or when you ask) and looked up by index; the web editor gets that list apart from the state and
  keeps it in the browser, so a state update is ~3 kB instead of ~100 kB; saving from the web editor answers
  at once; the entity chooser opens much faster
- Cache wissen: on the settings screen and in the web editor, forgets the cached entity list and fetches it again
- Searching in the entity chooser: the keyboard's button says "Zoek"
- Overig can be moved like the other areas (web editor)
- Web editor: drag and drop (⠿) in "Gekozen": cards within their area, and whole areas; works with a mouse and on a phone
- The tab to open on: the last one, Favorieten, Energie, an area or Overig (settings screen, web editor)

1.1.1
- A lamp that fades out no longer jumps back to "Aan" for a moment after you switch it off: the new state
  is held until Home Assistant reports it (at most 6 seconds after the last tap)
- A tap sends turn_on or turn_off as the card shows it, not toggle: off and at once on again no longer
  switches a lamp that is still fading out off a second time
- Web editor: the save bar no longer has the area headings of the lists on top of it

1.1.0
- Energie tab: electricity (now, today, sent back), solar panels, gas and water today, with a bar per hour;
  its own entities (Instellingen > Energie, or the web editor), today's use worked out from the meter readings
- Thermostats (climate): room temperature on the card; screen with target -/+, mode and presets
- Humidifiers: humidity on the card; screen with target -/+, on/off and modes
- Fans: speed on the card; screen with speed (slider, -/+ in the fan's steps), presets, oscillation, direction
- Speakers (media_player): double card with album art and keys; screen with volume, mute, power and source
- Cameras: double card with the still image; full screen that renews every 2 seconds
- Persons and device trackers: Thuis / Weg / zone and since when; screen with a map of the location
- Weather: double card with now and the forecast (weather.get_forecasts)
- Web editor: Energie section (a tab on phones)
- Fix: the entity list failed (HTTP 400) for entities without a unit

1.0.0
- First version: Home Assistant entities on the Toon (tile, list per area / name / own order, favourites)
- Setup on the Toon and in a web editor (http://<toon-ip>/homeassistant.html, port 8137)
- Entity chooser with search, area and type filters, rename and favourites
- Alarm panels with and without code (keypad for numeric codes)
- Optional Home Assistant icon in the systray
- Lights: brightness, colour and colour temperature (light screen from the list)
- Logo shown at the right size in the tile chooser
- Renamed to Home-Assistant Extended
- Web editor shows how to fix a missing connection: "Flush firewall rules" (Instellingen > TSC)
- Folder renamed to homeassistantExtended
- New main screen: areas as tabs (Favorieten first, Overig last), entities as cards, 9 per page
- Icons per type; cards light up when on, pulse until Home Assistant answers, notice when a command fails
- Alarm panels as a double card with their buttons; with a code the alarm screen opens with the mode chosen
- Set the order of the areas in the web editor; "Gekozen" is grouped per area
- Screenshots in the README
- After a command the state is fetched after 1 s and again after 3 s, so lamps that fade show the right state
- Settings screen: QR code and the full web editor address with the Toon's IP address
- Web editor works well on phones: tabs (Gekozen, Toevoegen, Verbinding), big touch targets, two-line rows, compact save bar
- Web editor ignores another app that uses the same WebSocket port
